# Icon Placeholder

Due to the limitations of the current environment, actual PNG icon files cannot be generated.

To complete the extension, you'll need to create icon files:
- icons/icon16.png (16x16 pixels)
- icons/icon32.png (32x32 pixels) 
- icons/icon48.png (48x48 pixels)
- icons/icon128.png (128x128 pixels)

The icon should represent a filter or media compass concept, using the NERtelenítő brand colors:
- Primary: #14B8A6 (teal)
- Secondary: #0f9d8a (darker teal)

You can use the create-icons.html file in the root directory to generate these icons using a web browser.
